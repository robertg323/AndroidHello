# AndroidHello

Android PDF viewer app built with Kotlin, Jetpack Compose, and Material3.

## Key Details

- Package: com.robertg323.androidhello
- Three source files: MainActivity.kt, PdfViewerScreen.kt, PdfRendererHelper.kt
- PDF rendering via Android built-in PdfRenderer (API 21+, no external deps)
- File selection via SAF (Storage Access Framework) ActivityResultContracts.OpenDocument
- Min SDK 24, Target/Compile SDK 35
- AGP 8.7.3, Kotlin 2.1.0, Compose BOM 2024.12.01, Gradle 8.11.1
